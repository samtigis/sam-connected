Panduan Menghubungkan HP (iPhone & Android)

1

Satu Jaringan Wi-Fi

Pastikan iPhone / Android dan PC Windows Anda terhubung ke jaringan Wi-Fi lokal yang sama.

Buka Aplikasi Client

Buka aplikasi Sam Connected di HP Anda. Pilih mode Client / Uploader.

3

Auto-Discovery mDNS

Aplikasi di HP akan otomatis mendeteksi server ini (SamConnectedStorage) tanpa perlu mengetik IP manual. Tekan "Hubungkan" dan foto akan mulai dicadangkan secara lokal!

Mengapa Sam Connected?

  • Privasi 100%: Foto dan video Anda tidak pernah menyentuh cloud publik (Google Photos / iCloud).
  • Kecepatan Wi-Fi Lokal: Backup berjalan dengan kecepatan maksimal router lokal (hingga ratusan Mbps).
  • Bebas Biaya Langganan: Anda dapat mencadangkan hingga puluhan Terabyte ke harddisk pribadi tanpa biaya bulanan.
  • Integritas File SHA-256: Mencegah duplikasi file dan memastikan file tidak rusak.
